# Хранилище паролей

Локальное приложение для хранения паролей. Записи лежат в SQLite, пароли шифруются Fernet, а мастер-пароль в базе сохраняется только как хеш SHA-256.

## Запуск

Дважды щёлкните `VPa05_2.exe`. Окно командной строки не открывается.

При первом запуске программа просит придумать мастер-пароль. При следующих запусках этот пароль нужен, чтобы открыть список.

## Что умеет

- **Новая запись** — название, логин и пароль, который собирается автоматически.
- Длина пароля от 1 до 64 символов, по умолчанию 16.
- Наборы символов: заглавные, строчные, цифры, спецсимволы.
- **Исключить похожие символы 0/O и l/I** — убирает ноль, заглавную `O`, строчную `l` и заглавную `I`.
- **Новый пароль** — только сгенерировать и скопировать, без записи в список.
- Список показывает названия и логины. Пароль виден после открытия записи.
- Пароль можно скопировать в буфер обмена.
- Запись удаляется из списка.

## Где лежат данные

Рядом с программой появляются два файла:

- `.key` — ключ шифрования;
- `password.db` — база с хешем мастер-пароля и зашифрованными записями.

Оба файла в Git не попадают. Если удалить их оба, следующий запуск создаст хранилище заново и попросит новый мастер-пароль. Старые записи при этом восстановить нельзя.

## Исходники

Нужен Python 3.11 или новее.

```text
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

Собрать exe заново:

```text
.venv\Scripts\python.exe -m PyInstaller --noconsole --onefile --name VPa05_2 --distpath . --workpath build --specpath build main.py
```

Код разделён так: `db.py` — база, `crypto.py` — ключ, хеш и генератор, `ui.py` — окно, `main.py` — запуск.
